🚀 Just built my first fully interactive Sales Dashboard using Python Dash
📎 Live Dashboard Link: https://lnkd.in/d5RscM7p
I wanted to combine my love for data with practical dashboarding skills — and this project helped me do exactly that.
📊 This dashboard provides a 360° view of store performance, including:
💰 Total Sales & Profit Analysis
📦 Order and Return Tracking
📈 Profit Margin Calculations
🌍 Region, Category, and Segment-wise insights
🔍 Users can interact with multiple filters such as:
 ➡️ Region
 ➡️ Category & Sub-Category
 ➡️ Segment
 ➡️ Ship Mode
 ➡️ Custom Date Range
💡 Tech Stack Used:
 🐍 Python (Dash + Plotly + Pandas)
 ☁️ Deployed on Render for live access
 📈 Responsive and interactive visualizations
✨ Key Highlights:
 ✅ Dynamic filtering with real-time updates
 ✅ KPIs auto-update on every selection
 ✅ Four interactive visualizations — bar, horizontal bar, and line charts
 ✅ Clean and mobile-friendly layout

🎯 What I learned:
 This project gave me hands-on experience in building a complete analytics app — from data preprocessing to visualization and deployment.
