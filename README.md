## 📊 Project Overview

I built a fully interactive <b style="color:#FF6A00;">Sales Analytics Dashboard</b> using Python Dash, combining data analysis with practical dashboard development.

This project delivers a complete <b style="color:#FF6A00;">360° view of store performance</b>, enabling real-time insights through dynamic filtering and interactive visualizations.

---

## 💼 Business Insights Covered

- 💰 Total Sales & Profit Analysis  
- 📦 Order & Return Tracking  
- 📈 Profit Margin Calculations  
- 🌍 Region, Category & Segment-wise Performance  

---

## 🔍 Interactive Features

Users can dynamically filter the dashboard using:

- ➡️ Region  
- ➡️ Category & Sub-Category  
- ➡️ Segment  
- ➡️ Ship Mode  
- ➡️ Custom Date Range  

All KPI cards and visualizations automatically update based on user selections.
